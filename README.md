# 生日贺卡

手机友好的互动生日贺卡，包含动态光晕与星空、蜡烛仪式、祝福礼物、好运签、愿望档案、音乐与可保存的纪念卡。

当前入口是 `index.html` 邀请页；浏览器通过完整邀请链接解密 `card.enc.json`。邀请钥匙不应提交到仓库。普通网址只能看到邀请提示；完整链接可以转发给其他人，并非登录身份白名单。

愿望与邀请访问分开：个人恢复码用于加密和恢复跨年档案。只有显示“已同步至云端”才代表服务器确认保存成功。换设备时输入原恢复码；建议另存愿望备份。恢复码不应提交到仓库或公开分享。

前端使用 GitHub Pages，档案服务独立部署。长期恢复需要继续保留原服务和兼容的数据格式。不会在一个月后自动删除。

发布时只更新经过验证的邀请页和加密包，避免上传私有素材、个人恢复码和本机存储。仓库中较早版本的静态样式/脚本未参与当前入口加载，历史提交不具备私密性。
